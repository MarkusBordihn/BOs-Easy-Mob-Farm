## Features 🔮

- Fabric, Forge and NeoForge support.
- Designed for server-friendly operation while optimizing performance on both the client and server
  sides.

## Mob Capture Cards 🃏

The mod introduces a new item called the **Mob Capture Card**, which will drop randomly from mobs
when killed. These cards can be used in the **Mob Farm** or to collect all the mobs in the game.

## Upgrades 🛠️

The mod introduces new upgrades to improve the performance of the Mob Farm.

### Enchantments 🌟

This includes enchantments like **Experience**, **Looting**, **Luck**, **Speed**, **Player killed**
and special enchantments like **Sheep Shearing**.

### Filters 🧹

The mod introduces new filters to sort out loot like **Flowers** or **Meat**.

### Slot Upgrades 🎰

The mod introduces new slot upgrades to increase the number of loot which can be stored and
processed
directly in the Mob Farm inventory or for further processing.

## Custom Loot tables 📦

The mod is using the provided loot tables from the mods.
This means if you adjust the loot tables for data files these changes are automatically considered
by this mod as well.
